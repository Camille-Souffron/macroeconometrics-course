Computational scope and qualifications

Every major course family has a live Python experiment. The qualifications below distinguish a methodological illustration from a complete paper replication and identify the desktop extensions. No benchmark result is substituted for a live estimator.

Full-covariance TVP-SV

Browser TVP-SV uses diagonal contemporaneous covariance and fixed state innovation variances. Mean-reverting or random-walk volatility and an explicit outlier mixture are available. Full time-varying triangular covariance with learned state scales adds thousands of latent states and requires multi-chain convergence assessment.

Full triangular covariance, learned coefficient/volatility/impact state scales, optional outlier mixture, NUTS/HMC/ADVI; no named-paper prior replication is claimed.

Reproducible implementation · tvp · tvp-sv · markov

Mixed-frequency estimation

The bundled common panel is quarterly and revised, not a monthly release-vintage panel. Quarterly observations cannot responsibly be interpolated into monthly observations. Browser DFM uses a genuine state-space likelihood; the native mixed-frequency implementation takes an explicitly dated monthly panel and quarterly growth.

Statsmodels DynamicFactorMQ with quarterly aggregation restrictions, EM and missing observations.

Reproducible implementation · dfm · favar

Pretrained forecasting models

PyTorch and pretrained Chronos checkpoints are not distributed in the pinned Pyodide runtime. Adding a separate tensor runtime and model weights would exceed the shared-runtime architecture and initial package budget. The browser trains real small RNN/LSTM/TCN/Transformer models; these are not called pretrained models.

Actual CPU Chronos-T5-tiny inference with a required model commit revision and fixed random seed.

Reproducible implementation · sequence · ml

Climate-risk covariates

The cited climate application requires observed local physical- and transition-risk covariates. No such replication dataset is bundled, and NFCI is not relabelled as a climate proxy. The supplied full function accepts observed climate covariates and unit identifiers.

Pooled quantile regression with climate covariates and unit effects. This is a method illustration, not a causal or exact paper replication.

Reproducible implementation · gar · dvar

Small-panel inference

The real 11-firm panel supports live pooled, Mean Group, hierarchical and collapsed difference/system GMM estimation. Eleven units do not justify reliable large-N overidentification or serial-correlation-test p-values; moment residuals and relevance are reported. The VARX network option imposes equal foreign-unit weights, not fabricated trade weights.

Genuine one-step moment estimation and partial-pooling Gibbs sampling. No claim that GMM removes every short-panel or weak-instrument problem.

Reproducible implementation · panel

Unit-root reference distributions

DF–GLS and the known-break exercise display Monte Carlo critical values for a specified Gaussian null, sample size and lag order. The known-break exercise is explicitly Perron-style, not a reproduction of every innovation/additive-outlier case in Perron (1989). Multiple-break locations minimise trimmed global SSR; no conventional F p-value is attached to a searched break date.

PP long-run variance correction, GLS detrending, known-break augmented regression, Chow test and global segmented regression.

Reproducible implementation · unit-roots · perron · breaks

Distributional forecast support

The direct-horizon DVAR estimates two conditional marginals using regularised distribution logits and a triangular factorisation. It differs from the cited three-variable empirical application. CDF interpolation stays on observed support; no parametric tail density, log score or structural policy interpretation is asserted.

Direct multi-step joint distribution forecasts and changes in growth quantiles/CDFs under an explicit conditioning scenario.

Reproducible implementation · dvar · distribution-regression · gar

DIC and conditional WAIC are model summaries, not replacements for chronological predictive validation.
